# School Website features
        User Management – Logging in, registering, and managing profiles

        Student Portal – Students view grades, assignments, announcements

        Teacher Portal – Teachers manage classes, upload results, share resources

        Administrative Portal – For managing the whole system and content

        Resource Center – A library for documents, past questions, and study materials

        News & Events – Announcements and upcoming events for the school

        Clubs & Societies – Pages for clubs like chess club, science club, etc

# User Management

        Students can create accounts
        Teachers can create accounts (or be added by admins)
        Verification to check whether user is a student in presec
        Login/logout functionality
        Password reset system

# Student Portal

        Students can view their grades and results
        Students can see upcoming school events
        Students can download past papers and study guides
        Students can update their profile (photo, contact info, etc.)

# Teacher Portal

        Teachers can upload results for their students
        Teachers can upload learning materials (PDFs, videos)

# Administrative Portal

        Admin can manage users (students, teachers)
        Admin can manage clubs and societies
        Admin can post news and announcements
        Admin can view site analytics (e.g., how many students logged in this week)

# Resource Center

        Upload resources organized by subject
        Search bar for resources
        Filter resources by class or topic

# News & Events

        Admin can create announcements
        Students and teachers can view events in a calendar format

# Clubs & Societies

        Dedicated pages for each club
        Club leaders can post updates
        Event scheduling for clubs
